## 📌 Competências previstas por projeto

### 1. Landing page responsiva
- HTML semântico
- CSS com Flexbox e Grid, mobile-first
- Variáveis CSS e tipografia fluida
- Fidelidade a um layout do Figma
- Acessibilidade básica

### 2. Dashboard com API pública
- Requisições assíncronas (fetch, async/await)
- Estados de loading, erro e vazio
- Busca com debounce, filtros e paginação
- Manipulação de dados com map, filter e reduce

### 3. App de tarefas / finanças
- CRUD completo
- Gerenciamento de estado
- Componentização
- Persistência com localStorage
- Diferencial: drag-and-drop e TypeScript

### 4. Formulário multi-etapas
- Validação (React Hook Form + Zod)
- Mensagens de erro e máscaras de input
- Acessibilidade: labels, foco, teclado, aria-live

### 5. Biblioteca de componentes
- Componentes reutilizáveis e design tokens
- Tema claro/escuro
- Documentação com Storybook
- Testes com Vitest + Testing Library

### 6. E-commerce simples
- Rotas dinâmicas
- Estado global do carrinho
- Performance: lazy loading e code splitting
- SEO básico
- Diferencial: testes E2E com Playwright

## 🛠️ Stack prevista
`HTML` `CSS` `JavaScript` `TypeScript` `React` `Vite` `Vitest` `Storybook`
